# Sobol 全量敏感性：完成结果与解释

1,792 个样本全部完成，数值进程退出码 0，耗时 18,779.987 秒。每点都真实执行两遍完整硬件重选；每个候选、每个窗口又执行两遍物理模型回放。所有重复结果一致，冻结的 8 份数值源码与启动快照逐字节一致。

计时采用 Python 阶段流体分析模型，遵守有限容量与共享带宽、端口约束。本次扫描不包含原生 HBM 或 RTL 校准。

本节只使用同一组 **18 个开发窗口**、`pipelined` 模式和 BF16。每点的响应定义为：

`delta = 三个双核比例族（5+1、4+2、3+3）中最好已评估候选的开发集延迟几何平均 / 最好已评估单核的开发集延迟几何平均 − 1`。

评分采用离线分配与 LPT 的可执行回放。H33 允许两个核计算形状相同；CSV 中的 `hetero_ms`、`hetero_family` 是沿用的字段名，实际含义是上述三个双核族的已测最佳候选。它们不是严格异构的全域最优解。留出窗口不参与这一步重选。

## Sobol 指数与置信范围

表内数字为无量纲估计，`±` 是 SALib 的 95% 置信半宽（100 次重采样）。所有 S1、ST、半宽已从完整 delta CSV 独立重算，发布值与重算值的最大差异为 **0**。

| 参数 | 扫描范围 | 一阶 S1 ± 半宽 | 总效应 ST ± 半宽 |
|---|---|---:|---:|
| 4 KiB 基准权重服务周期 | 1～30.4 周期 | 0.1492 ± 0.2042 | 1.0156 ± 0.2607 |
| bank 带宽 | 8～32 B/bank/周期 | −0.0495 ± 0.1254 | 0.5454 ± 0.2478 |
| 点积流水服务周期 | 1～4 周期 | 0.0025 ± 0.0038 | 0.0441 ± 0.0600 |

| vector 服务倍率 | 0.5～2 | 0 ± 0 | 0 ± 0 |

这些指数描述的是**有限预算搜索程序及其最好已测候选**对参数的敏感性，不是全域最优硬件的指数。参数改变还会引起所选硬件跳变。负的一阶估计和大于 1 的总效应估计来自有限样本估计及较宽的置信范围，保留原值，不截断到 `[0,1]`。总效应不可相加成性能占比；bank 与 credits 的总效应置信区间重叠，不能确定两者的稳定排名。vector 的 0 只适用于这里的响应和工作区间。
