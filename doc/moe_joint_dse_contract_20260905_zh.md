# MoE 大小核联合 DSE：冻结搜索契约

目标：在相同 HBM、乘法器总数和存储容量约束下，确定本次有限网格内最好的单核、同构双核、等 PE 异形双核、大小核；检查大小核是否比经过同等搜索的单核更快。结果为固定路由 MoE FFN 的仿真证据，不是完整模型、RTL 时序或等面积结论。

## 搜索与公平性

- 37 种核心组合：6 单核、5 同构双核、10 等 PE 异形双核、16 个 3072+1024 PE 大小核。
- 单核/每个子核的 BLEN 候选为 2、4、8、16、32、64；MLEN 候选为 64、128、192、256、384、512、768、1024、1536、2048。保留 MLEN 可被 BLEN 整除且组合总 PE 为 4096 的组合。BLEN 同时是 M/N 分块宽度，MLEN 是 K 分块宽度。
- 每核预取槽共同取 2/3/4；全局 DMA credits 64/128；原始布局/scale 行距为奇数个 32B 扇区的布局；双核任务偏好阈值 M=1/8/32。调度器无合适首选任务时可窃取另一类任务。
- vector/accumulator 容量分配取均分、按 PE 比例、反向 PE 比例。仅当所有搜索输入中每个专家任务的逐核准入掩码完全相同，才合并容量变体。代码中这两项容量只用于准入/校验，任务进入后不改变时间；该等价证明只覆盖列出的输入。保留全部原始变体及其代表映射。
- 共 3420 个变体：20 个因 DMA 描述符容量不足被排除，3400 个可行变体归为 1180 个执行代表；每个代表跑四个输入，共 **4720 次完整 Rust 数值执行**。
- 统一预算：4096 PE，vector SRAM 4 MiB，accumulator 1 MiB（包括流水状态），weight SRAM 64 KiB，DMA frontend 44 KiB（包含 response staging、MSHR、waiter、native tracker、tile descriptor），combine SRAM 4 MiB，dispatch 16 KiB。
- weight SRAM 按 PE 比例分配；片上 activation 供数总量固定为 1024 BF16 元素/周期并按 PE 比例分配。共享 vector 功能单元仍为 512 元素/周期，两者是不同资源。
- 统一 1 ns 架构周期、8 通道同一 HBM2 配置、32B 原生交易；DMA 每通道注入、sector read 和在途合并开启；四个查询端口，查询延迟/启动间隔均为 2 周期；八个 32B/周期回包端口。
- 不搜索：三核以上、矩形 M/N 阵列、逐核不同槽数、其他 activation 带宽分配、其他量化格式、prefill。上述范围以外不能声称全局最优。

## 执行与验收

每个代表都实际执行地址读取、codec 解码、三个 GEMM、SwiGLU、路由还原和加权合并；结果要求与独立 oracle 的 BF16 输出逐位一致，并通过实际 HBM 请求字节、队列、SRAM 和端口检查。输出完整保留为 gzip JSON；压缩只减磁盘用量，不省略证据。

全网格无失败、缺点或超时后才生成排名。每类选一个跨四输入几何平均延迟最小的固定配置，禁止每个输入换一套硬件后当成一个方案。四类胜者在原输入各额外执行两次，所有数值、周期和原生计数必须一致。

在看排名前冻结四个 holdout 路由窗口：同一模型/layer/step 上，B8 从原 cohort start+64 起选有效 stream，B32 从 start+96 起选，保证和调参窗口及另一 holdout batch 坐标不重叠。胜者固定后各执行两次，不能根据 holdout 改胜者。它们仍只有两个模型家族，且是同样的合成权重生成方法；不能作为完整模型泛化证据。

## 时序假设与敏感性

计算服务周期为 `max(BLEN, ceil(BLEN*MLEN/activation_supply))`，另计 `ceil(log2 MLEN)+16` 的结果就绪延迟。这是一项明确的供数下界约束，**不是 RTL 校准**。

现有 RTL 可看到 matrix SRAM 请求/返回寄存、MLEN 宽数据接口与阵列流水，但不能直接证明新的 BF16 normal-buffer 双核通路具有此吞吐。最终固定胜者还要分别复测 activation 总带宽 512/2048、lookup 启动间隔 1（延迟仍为 2）、旧串行矩阵时序、无查询/回包计时的乐观直通对照。它们是独立假设敏感性，不能当成在每一种假设下都重做了全网格优化。

如果大小核只在某一未经校准的计时假设下获胜，则结论必须保留条件；如果仍落后，也不能直接归咎 HBM Controller 或宣布所有 MoE 大小核设计无效。
